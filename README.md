# 数据湖治理配置中心

离线版数据湖治理配置工具，涵盖多源接入通道、分层表结构设计、湖区分区策略、流批转换编排、元数据编目检索与资源计量管理，所有配置持久化到浏览器本地存储。

这是一个**纯前端**管理平台：React + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `lake-govern-config:entries` 这一项，或调用 `resetModule(模块)`。

## 分区归档执行

湖区分区模块除了保留天数、冷热分层等方案配置，还提供「分区归档执行」面板（`src/views/lakezone/ArchivePanel.tsx`），
领域规则集中在 `src/api/archive-service.ts`，产物单独持久化（不复用条目数据的 key）：

- `lake-govern-config:archive-files`：按分区字段、粒度、保留天数、冷热分层算出的分区文件与归档保留结论。
- `lake-govern-config:archive-windows`：归档窗口（方案 + 当天为幂等键）及成功/失败计数。
- `lake-govern-config:archive-packages`：归档结果压缩包与上传结论。

关键规则：

1. **分区方案可核对**：根据分区字段、分区粒度（按小时/天/月）、保留天数、冷热分层阈值回看生成分区文件，
   标注热层/冷层/待归档/已过期，并为每次计算生成口径签名。
2. **新旧口径冲突以已启用方案为准**：同一目标表存在已启用的其它方案时，非启用方案的归档会被拦截；
   已生成的旧分区文件按原口径冻结保留（`历史口径=true`），不参与新窗口归档，也不会被回滚。
3. **窗口幂等**：同一方案同一天重复触发归档只产生一次结果，后续触发直接返回首次结论。
4. **失败续做不回滚**：可模拟部分分区归档失败，续做只处理「归档失败」文件，已成功文件保持已归档。
5. **跨模块快照队列**：每个进入窗口的分区文件都会在版本快照模块 upsert 一条「待创建」备份记录
   （带 `来源分区文件`/`归档窗口` 字段），续做成功原地更新、编号不变；历史手工快照取值不变。
6. **压缩包与上传**：压缩包（纯前端 STORE 模式 ZIP，见 `src/api/zip-writer.ts`）清单必须与版本快照页
   待创建队列一致才允许打包/上传；队列漂移会被拒绝。面板的「清空归档演示数据」只清理归档产物及其备份记录。

领域规则验证（单入口打包后在 Node 里跑 45 项断言，含口径冲突、幂等、续做、队列一致性）：

```bash
make verify          # 或 cd frontend && npm run verify:archive
```
